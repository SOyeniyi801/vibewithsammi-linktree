# Vibe With Sammi — Link Hub

A custom link hub for **Vibe With Sammi**, designed and developed by Sammi Oyeniyi.

Built as a branded alternative to Linktree, bringing together my creative work, professional portfolio, photography, media kit, social platforms, and favorite tools in one place.

## About

I'm Sammi — a designer, storyteller, and creative based in Atlanta.

This link hub connects the different parts of my creative world, including:

- Floye Creative Co. — Creative Studio
- Professional Portfolio
- Media Kit
- Photography
- Social Media
- Brand Partnerships + Affiliate Links

## Design

The visual direction pulls from the branding of **Floye Creative Co.** while giving Vibe With Sammi its own playful personality.

Features include:

- Bold blue + pale yellow color palette
- Chunky 3D-style buttons
- Black outlines and hard shadows
- Animated GIF profile image
- Interactive hover states
- Responsive mobile-first layout
- Social media shortcuts

## Built With

- HTML
- CSS

- Font Awesome
